Apscios OS Documentation

Overview

Apscios OS is a custom Linux distribution based on Fedora Workstation.

How to Build

To produce the ISO, you need a Linux machine with xorriso and syslinux installed.

git clone <repo-url>
cd apscios-os
./scripts/download_fedora.sh
./scripts/build_iso.sh

How to Run

You can test the ISO using QEMU:

./scripts/run_vm.sh
